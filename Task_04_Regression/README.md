# Task 4 - Supervised Learning (Regression)

## Objective
Predict project budget using project features.

## Dataset Features
- Team Size
- Duration Months
- Client Meetings

## Target Variable
- Budget

## Models Used
1. Linear Regression
2. Ridge Regression

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R2 Score

## Results
The Linear Regression and Ridge Regression models were trained and evaluated. Actual vs Predicted values were plotted for performance visualization.

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Performance Analysis
The Linear Regression and Ridge Regression models were trained to predict project budgets using project features. Both models performed well and showed a strong relationship between the input features and budget. The R² score indicates that the models can explain most of the variation in the budget data, while the MAE, MSE, and RMSE values show that prediction errors are relatively low. The Actual vs Predicted plot demonstrates that most predicted values are close to the actual values, indicating good model performance. Overall, the regression models are effective for budget prediction, with Ridge Regression helping to improve model stability and reduce overfitting.
